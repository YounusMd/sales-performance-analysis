# Sales Performance Dashboard

## Project Overview
This project analyzes sample sales data to summarize revenue, orders, units sold, and regional sales performance using Microsoft Excel.

## Project Files
- `sales_data.xlsx` — Raw sales data containing 240 rows.
- `sales_dashboard_and_data.xlsx` — Excel workbook containing KPI calculations and a regional sales chart.
- `power_bi_build_guide.md` — Instructions for recreating the report in Power BI.

## Tools
- Microsoft Excel
- Power BI Desktop (optional recreation)

## Key Performance Indicators
- Total Revenue
- Total Orders
- Units Sold

## Business Questions
1. Which region has the highest revenue?
2. Which product category contributes the most revenue?
3. Which salesperson has the highest sales?
4. How does revenue change month by month?

## How to Use
1. Open `sales_data.xlsx` to explore the raw data.
2. Open `sales_dashboard_and_data.xlsx` to view the KPI figures and regional sales chart.
3. Follow `power_bi_build_guide.md` to recreate the report in Power BI.

## Dataset Note
The 240 rows are synthetic sample data created for learning and portfolio practice. They do not represent real company transactions or actual business performance.
